What is proved

The exact static catalog contains 193 registrations at NetFns ≥ 0x2e and 192 unique addresses. The existing detailed catalog overlaps 49, leaving an original Limbo backlog of 143. Those addresses contain 144 registration rows because 0x30/0x26 is registered twice. At least one handler resolves for 72 addresses; 71 have no resolved handler. The duplicate's raw second target remains zero, but its precedence is now closed by the exact first-match lookup implementation.

The exact shared SubCmdHandler implementation and its targets are now closed once: five addresses expose 32 host-reachable operations and two more are registered-but-empty overlays. Request/response layouts, static authorization/channel predicates, effects and completions are recorded in the SubCmdHandler contract report. Runnable codecs and live behavior remain open.

The seven-address chassis identity/config family is also closed statically. This proves 0x30/0x26 row 116 wins the linear first-match dispatcher lookup and the later zero-target duplicate is shadowed.

The four-address peripheral-controller reset family is closed as a static state machine. The initiating route stages masks and deferred timers, while read/sync/query routes expose or persist status. Timer callbacks, physical effects, runnable codecs, and live behavior remain explicitly open.

The two-address reset-to-default pair shares one exact destructive libosa implementation. Successful action completion acknowledges detached-thread creation, not backend reset success; both routes remain intentionally non-runnable.

The three-address Extended Configuration family now has a decoded reservation/chunking transport and exact selector-license map. Its Get/Set backends contain selector-specific configuration and Remote File Share behavior, so the family remains partial and does not reduce the 123-address backlog.

Closure order

17 P0 addresses have decoded/likely selectors, named high-impact effects, or duplicate-registration precedence; 79 P1 addresses primarily need handler identity or non-admin authorization resolved; 27 P2 addresses are resolved read-like/admin routes whose codecs and channel gates remain open. Priority is triage, not a security finding.
