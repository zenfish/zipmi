Reset-to-default command pair

Two Administrator-only wire addresses bind one exact libosa implementation. Nonzero accepted selectors launch detached destructive work; command success acknowledges thread creation, not reset completion.

Provider correction

The earlier gap ledger's liboemcmds library label identified table ownership, not implementation ownership. These closed rows identify libosa as the implementation provider.

liboemcmds imports the symbol; exact-image libosa uniquely defines CmdResetToDefault at 0x44b061a4. The worker GOT relocation resolves to threadResetToDefault.

Gates and completions

Administrator at dispatch. The local-config-disabled predicate rejects only KCS-class requests. A reset lock produces 0xd4; active firmware update produces 0xc0. Other decoded completions: 0xc7 bad length, 0xcc bad selector, and 0xff thread setup failure.

Safety boundary

The worker removes jobs, then calls configuration-reset backends. Backend failures are logged after the IPMI command already returned success. These routes remain intentionally non-runnable.
