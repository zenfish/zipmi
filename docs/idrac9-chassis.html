Important static findings

  • Set Name trusts its embedded length instead of the outer request length.
  • Set Service Tag truncates to eight bytes and stages asynchronous state rather than persisting immediately.
  • Sync Service Tag logs cfgdb/backend failures but still reports success.
  • Channel 5 adds synchronization side effects; it is not rejected.
