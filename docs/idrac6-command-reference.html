Denominator boundary

189 is the closed top-level effective dispatch-route denominator, not a closed semantic-operation denominator. Thirty-two routes now have 160 reachable semantic paths decoded (151 successful-operation paths, two successful no-ops, and seven explicit unsupported terminals); remaining multiplexed handlers are unexpanded, and raw control-flow branches are never counted as operations.

Why 213, 195, and 192 all appeared

  • Correct raw registration-slot count (120 + 93).
  • Same cardinality as the exact unique-address set, but not the same set.
  • A name/alias inventory, not a dispatch denominator.

The legacy generator remapped seven OEM-overlay rows whose descriptor NetFn is 0x00 as if they were NetFn 0x30, replacing seven real non-0x30 routes. Separate handler-name aliases add further non-denominator names.

Recovered semantic paths

The 32 modeled routes contain 160 reachable paths: 151 successful-operation paths, 2 successful no-op state paths, and 7 explicit unsupported terminals. The two Reset-to-Default addresses intentionally reuse one implementation contract. Validation, logging, and backend-error branches are not counted as operations.

User credential provider chain

0x06/0x43..0x47 retain five distinct address overlays but share one proved provider dispatcher. UserInfoInit registers UserInfoAccessHandleFunction for opcode class 0x0200; opcodes 0x0201..0x0205 resolve to five exact-image leaf functions. IPMB, KCS, LAN, and serial callbacks do not consume this class and fall through with provider-miss 7. All dispatcher, callback, and leaf identities are body-hash bound in the JSON artifact.

Cumulative modeled routes: 32; effective routes still unexpanded: 157.

Channel-access provider chain

0x06/0x40 and 0x06/0x41 share the exact ChannelDataAccess precedence contract but retain separate Set/Get wire, privilege, firewall, effect, response, and completion overlays. Opcodes 0x0105/0x0106 are consumed directly by LAN and serial callbacks. IPMB and KCS return provider-miss 7, and the registered generic 0x0100 session provider also rejects these opcodes, making channel type part of reachability. Exact wrapper, dispatcher, callback, leaf, session-state helper, and firewall identities are body-hash bound in the JSON artifact; raw ARM evidence is retained in channel-access-r2-disassembly.txt.

Watchdog state and action engine

0x06/(22, 24, 25) share one exact 24-byte G_sWatchdogTimer state object, main/pre-timeout ThreadX timers, and asynchronous event/action engine. Reset recomputes and rearms the current configuration; Set replaces it and may stop, fire, or arm the timers; Get returns configuration plus the live countdown. The three route overlays remain separate: Set is Operator and requires four firewall subfunctions, Reset is Operator, and Get is User. The Set wrapper reads bytes 8..13 without a local declared-length check and can return raw 0x01 on timer activation failure. Exact helper identities are body-hash bound in JSON; raw ARM evidence is retained in watchdog-r2-disassembly.txt.
