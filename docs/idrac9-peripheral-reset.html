Peripheral-controller reset family

Four Administrator-only OEM addresses form one state-machine family. The initiating route stages state and deferred timers; this report intentionally does not turn that state-changing route into a runnable codec.

0x30/0x48 · stage

0x30/0x48 accepts target selector 1..3, marks state 0x15, mutates masks, and schedules deferred timers

0x30/0x49 · read

0x30/0x49 returns two cached bytes; a channel-5 read may clear state 0x15

0x30/0x4a · sync

0x30/0x4a accepts record selector 1..2, updates cache and cfgdb, and marks the corresponding pending-status bit

0x30/0x4b · query

0x30/0x4b maps pending/completion masks to status 2 or 3, or returns selector-specific cfgdb status

Safety and unknowns

  • Every registration requires Administrator privilege; no second internal role check was decoded.
  • The initiating and synchronizing handlers read embedded fields without a decoded outer-length guard.
  • Timer setup failures on the initiating route are logged but still return success.
  • Timer callbacks and physical consequences remain outside this bounded static closure; all four routes remain non-runnable.
